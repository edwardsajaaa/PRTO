# Project Portfolio Website

Portfolio website ini dibangun menggunakan tech stack modern untuk menunjukkan skill development yang profesional.

## Tech Stack

- **Framework**: Next.js 14+ dengan App Router
- **Bahasa**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Shadcn/ui
- **Animasi**: Framer Motion
- **Content**: MDX

## Fitur

- Responsive design
- Dark mode support
- Smooth animations
- SEO optimized
- Type-safe development
