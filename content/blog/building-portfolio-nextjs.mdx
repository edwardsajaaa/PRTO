# Membangun Portfolio dengan Next.js

Dalam artikel ini, saya akan berbagi pengalaman membangun portfolio menggunakan Next.js dan tech stack modern.

## Mengapa Next.js?

Next.js menawarkan banyak keuntungan:

1. **Server-Side Rendering (SSR)** untuk SEO yang lebih baik
2. **App Router** untuk routing yang modern dan fleksibel
3. **Image Optimization** built-in
4. **TypeScript** support yang excellent

## Tech Stack Pilihan

Berikut adalah tech stack yang saya gunakan:

- Next.js 14+
- TypeScript
- Tailwind CSS
- Shadcn/ui
- Framer Motion
- MDX

Setiap tool dipilih dengan alasan yang jelas untuk menunjukkan kemampuan profesional.
